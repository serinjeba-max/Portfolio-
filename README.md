# Serin Jeba D 

This is a responsive personal portfolio website for Serin Jeba D, built using plain HTML, CSS, and JavaScript for easy deployment on GitHub Pages.

## Files

- `index.html` — portfolio structure and content
- `styles.css` — styling, layout, and responsive design
- `script.js` — light/dark mode toggle and reveal-on-scroll behavior
- `assets/Serin_Jeba_D_Resume.pdf` — downloadable resume file

## Local preview

Open `index.html` in a browser, or run a local static server:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000

## GitHub Pages deployment

1. Push this project to a GitHub repository.
2. Open the repository in GitHub.
3. Go to Settings > Pages.
4. Set the source to `Deploy from a branch` and choose the `main` branch.
5. Save the settings.

Your site will be published at:

`https://<your-username>.github.io/<repository-name>/`
